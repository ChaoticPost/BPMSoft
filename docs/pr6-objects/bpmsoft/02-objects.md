# Фаза 3. Объекты (24 бизнес-сущности + 1 техническая связка)

Порядок важен: lookup-колонка создаётся только на уже существующий объект.
Для каждого объекта: конфигуратор → пакет `Chugunova_package` → «Добавить → Объект»
→ код, заголовок, родитель «Базовый объект» → колонки «+» → **Сохранить →
Опубликовать** → переоткрыть и проверить.

Обозначения: **Обяз.** — «Да» ставить и в свойстве колонки, и в бизнес-правиле
страницы; «Нет» — необязательное ([0..1] в UML). Тип «Справочник» = Lookup
на объект/справочник из правой колонки. Пометка `(связь N)` — колонка
реализует UML-связь из `03-links-ui.md`.

> Колонка `Name` есть не у всех родительских объектов — если платформа скажет,
> что колонка уже существует, не создавать дубликат.

## Контроль после каждого объекта

- [ ] Объект в списке пакета `Chugunova_package`, родитель «Базовый объект».
- [ ] Все колонки на месте: код, заголовок, тип, обязательность.
- [ ] Lookup-колонки смотрят на правильные объекты/справочники.
- [ ] «Сохранить → Опубликовать» подтверждено; объект переоткрыт, колонки сохранились.
- [ ] Скриншот колонок/карточки объекта в нужную папку (`02_Objects`).
- [ ] Если имя колонки конфликтовало — записано, какое имя присвоила платформа.
